# Code of conduct

playcal follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, criticise ideas and code rather than people, and no harassment of any kind, in issues, pull requests, discussions or anywhere else the project is represented.

Report problems privately to the maintainer at rizgarozan7@gmail.com. Reports are kept confidential. The maintainer may remove comments, close threads or block people who break these rules.
